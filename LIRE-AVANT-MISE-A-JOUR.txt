Ce ZIP contient les fichiers modifiés seulement
Il doit compléter votre projet existant, pas être publié seul

1 — Décompressez le ZIP dans un dossier temporaire
2 — Copiez index.html, solutions.html, a-propos.html, contact.html et style.css dans votre projet digital_energie en acceptant leur remplacement
3 — Copiez le contenu du dossier assets dans le dossier assets de votre projet
    Conservez les autres images déjà présentes
4 — Ouvrez index.html ou votre aperçu Live Server pour regarder la nouvelle identité
5 — Dans le terminal VS Code, à la racine de votre projet :

    git add .
    git commit -m "Nouveau logo officiel et couleurs Digital Energies"
    git push
